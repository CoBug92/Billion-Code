# Источники данных графа

## Американские миллиардеры — выпуск 2026

Базовый охват фиксируется по годовому списку **Forbes World’s Billionaires 2026** со срезом состояния на 1 марта 2026 года. В него входят 989 записей с гражданством США. В граф также добавлены люди, на которых ссылаются связанные профили базового списка; они не учитываются в числе 989.

- Годовой список, место и оценка состояния: [Forbes World’s Billionaires](https://www.forbes.com/billionaires/).
- Дата рождения, образование, место проживания, организация, должность, отрасль, источники состояния и связанные профили: открытый проект [komed3/rtb-api](https://github.com/komed3/rtb-api), лицензия MIT.
- Русские отображаемые имена и часть портретов: Wikipedia и Wikidata; при отсутствии русского имени импорт использует транслитерацию.
- Остальные портреты локального fixture: изображения из публичных профилей Forbes. Они не очищены для публикации.

Скрипт `./scripts/enrich-american-catalog` повторно получает русские имена и URL портретов для `american-billionaires-2026.json`. Ему нужен сетевой доступ; `--repair` выполняет только локальную нормализацию уже импортированных данных и исправляет известные артефакты транслитерации.
- Подготовленный снимок приложения: `Main/Resources/Content/american-billionaires-2026.json`.
- Воспроизводимый импорт: `scripts/import-american-billionaires`.

Пустое поле означает, что источник не опубликовал значение. Приложение не подставляет вымышленный университет, компанию или дату рождения. Поэтому «полный охват» означает наличие всех 989 записей рейтинга и всех доступных в указанных источниках полей, а не утверждение, что публично известна каждая деталь биографии.
