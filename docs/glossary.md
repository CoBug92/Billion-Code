# Глоссарий

- **Доказательная связь** — отношение между двумя сущностями, для которого опубликованы проверяемые claims и источники.
- **Подтверждённая связь** — связь со статусом `confirmed`, прошедшая редакционный стандарт для своего уровня риска.
- **Оспариваемая связь** — связь со статусом `disputed`, для которой существуют авторитетные противоречащие свидетельства. Это не слух и не «вероятная связь».
- **Структурная общность** — связь через общий узел, например университет или компанию; сама по себе не доказывает личного знакомства людей.
- **Claim** — минимальное публикуемое утверждение, связанное с одним или несколькими источниками.
- **Source** — библиографическое описание основания claim; хранение ссылки не означает право копировать исходный материал.
- **Оценка состояния** — датированная модельная величина в USD, а не точный банковский баланс.
- **Человек дня** — профиль, назначенный редакционным расписанием для локальной календарной даты пользователя.
- **Dataset** — неизменяемый JSON-набор редакционного контента одной версии.
- **Manifest** — небольшой JSON-документ, указывающий приложению актуальный dataset и его параметры проверки.
- **Content snapshot** — полностью проверенное неизменяемое доменное представление dataset, доступное UI.
- **Bundled seed** — валидный набор контента, поставляемый внутри приложения для первого offline-запуска.
- **Current / previous** — текущая и предыдущая валидные версии удалённого dataset в локальном хранилище.
- **Schema validation** — проверка JSON-формы, типов, enum и обязательных полей.
- **Domain validation** — проверка ссылочной целостности, уникальности ID и редакционных инвариантов, которые не выражаются обычной JSON Schema.
- **World coordinates** — стабильная координатная система графа, независимая от масштаба и положения камеры.
- **Spike** — ограниченный технический эксперимент, который проверяет риск, но не является production-реализацией.
- **PII** — информация, позволяющая прямо идентифицировать пользователя.
- **App-instance ID** — псевдонимный идентификатор установки, который использует Firebase Analytics; его нельзя называть анонимным.
- **Скрейпинг** — автоматизированное извлечение данных со страниц или API, часто без специального экспортного контракта. Техническая доступность скрейпинга не означает право повторно публиковать полученные тексты, рейтинги или изображения.
