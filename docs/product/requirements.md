# Требования к MVP

- Статус: `accepted` для продукта, `proposed` для технической реализации
- Платформа: iPhone, portrait-only, iOS 18+
- Распространение: закрытый TestFlight
- Последнее обновление: 2026-09-05

## Границы

MVP проверяет ценность доказательного исследования 15 глубоких профилей. Он не проверяет масштаб каталога, монетизацию, социальные механики или real-time финансовый tracker.

## Функциональные требования

| ID | Требование | Критерий приёмки |
|---|---|---|
| FR-001 | Приложение открывается с графом человека дня | При наличии валидного snapshot выбран выпуск для локальной даты и показан его центральный узел |
| FR-002 | Нижняя панель раскрывает список людей | Панель имеет collapsed/medium/expanded состояния; положение графа сохраняется |
| FR-003 | Поиск находит человека по локализованному имени | Запрос обрабатывается локально и не передаётся в аналитику |
| FR-004 | Тап по узлу открывает карточку и центрирует камеру | Координаты других узлов не меняются; соседние узлы раскрываются до лимита сцены |
| FR-005 | Пользователь открывает связи выбранного узла | Список показывает kind, период, статус, объяснение и связанные claims |
| FR-006 | Подтверждённые и оспариваемые связи различимы | Помимо линии используются текст и accessibility label |
| FR-007 | Профиль объясняет происхождение состояния | Присутствуют сюжет, состав капитала, стартовые условия и таймлайн |
| FR-008 | Оценка состояния не выдаётся за точный баланс | В досье видна сумма в USD без даты и атрибуции в заголовке; дата и источник сохраняются в редакционных данных |
| FR-009 | Образование описано точно | Различаются `attended`, `graduated`, `degree` и неизвестный статус не подменяется окончанием |
| FR-010 | Существенные тезисы имеют редакционные источники | Библиография и дата проверки сохраняются в данных; отдельные evidence-кнопка и экран не входят в досье |
| FR-011 | Приложение работает без сети | При первом запуске доступен bundled seed; затем используется last-known-good cache |
| FR-012 | Удалённый контент обновляется безопасно | Невалидный payload не заменяет current snapshot |
| FR-013 | Доступны методология, privacy, лицензии и исправления | Настройки содержат версии документов, канал исправлений и сведения об аналитике |
| FR-014 | Firebase получает только разрешённые custom events | Произвольный текст, поиск, email, URL и PII отсутствуют |
| FR-015 | Досье компании объясняет деятельность, людей и ключевые события | Под названием видны известные годы деятельности; вид деятельности не дублируется; соучредители и связанные люди показаны отдельными облаками; чувствительные события хронологии имеют источник |
| FR-016 | Досье университета разделяет тип и связанных людей | Под названием виден период существования; compact-выпускники показаны отдельными синими облаками с годами обучения; expanded-блок «Люди и программы» показывает синие облака людей без годов; общий блок фактов отсутствует |

## Контент профиля

Обязательные блоки:

1. Имя, портрет и краткая идентификация.
2. Сумма оценки состояния без даты и источника в интерфейсе досье.
3. Состав капитала; источники сохраняются в редакционных данных.
4. Сюжет «как сформировалось состояние».
5. Стартовые условия и наследство.
6. Таймлайн минимум из шести событий.
7. Образование.
8. Доказательные связи.
9. Существенные споры и судебные эпизоды.
10. Дата последней полной редакционной проверки.

## Нефункциональные требования

| ID | Требование |
|---|---|
| NFR-001 | UI не ждёт сеть для показа валидного seed/cache snapshot |
| NFR-002 | Manifest не превышает 128 KiB, dataset — 5 MiB |
| NFR-003 | Одновременно видимы не более 40 узлов и 80 рёбер |
| NFR-004 | Все интерактивные цели не меньше 44×44 pt |
| NFR-005 | Все пользовательские строки локализованы; каноническая локаль v1 — `ru` |
| NFR-006 | Поддерживаются light/dark, Dynamic Type и Reduce Motion |
| NFR-007 | Функциональность графа дублируется доступным структурированным списком |
| NFR-008 | Неподдерживаемая schema и нарушение domain invariants отклоняют release целиком |
| NFR-009 | Current dataset не удаляется при нехватке места или неудачном refresh |
| NFR-010 | Контентные и аналитические ошибки не содержат PII или свободный текст |

## Состояния интерфейса

- `seed` — bundled content, обновление ещё не получено;
- `cached` — показан сохранённый snapshot;
- `refreshing` — идёт неблокирующая проверка обновления;
- `fresh` — актуальная версия успешно подтверждена;
- `stale` — оценка состояния старше 45 дней;
- `requiresAppUpdate` — manifest требует более новый reader build;
- `fatalSeedFailure` — bundled seed не может быть прочитан; показывается блокирующий recovery-экран.

## Не входит в MVP

- регистрация и синхронизация;
- платежи и подписка;
- push-уведомления;
- избранное и история;
- шаринг и deep links;
- пользовательский path builder;
- комментарии и UGC;
- CMS;
- iPad, landscape, macOS, Android и web;
- AI-вывод связей и автоматический пересказ без редактора;
- скрейпинг закрытых рейтингов;
- live-котировки и инвестиционные рекомендации.

## Зависимости и блокеры

- Публичное распространение невозможно без проверки прав на данные и изображения.
- Firebase disclosure уточняется по фактическому privacy report SDK.
- Производительность и accessibility графа должны быть подтверждены отдельным spike.
