# ADR-0007: renderer графа как редакционный атлас глав

- Статус продуктового эксперимента: `superseded`
- Статус renderer: `superseded`
- Дата: 2026-09-01
- Decision register: P-021, T-008
- Заменяет renderer-часть: [ADR-0003](0003-evidence-graph.md)
- Заменён: [ADR-0008](0008-obsidian-evidence-network.md)

## Контекст и ограничения

Source-backed people-only spike подтвердил, что полная organic network технически отображается, но одновременно показывает слишком много равнозначных линий и не создаёт ясной редакционной композиции. Evidence model, schema v1 и правило «общий контекст не равен личному знакомству» остаются обязательными.

Текущий seed содержит пять доказанных организационных контекстов. Они могут задавать последовательность глав, не становясь интерактивными graph nodes и не изменяя canonical content.

## Рассмотренные варианты

1. Оставить одну полную organic network и только улучшить стили.
2. Показывать смешанный граф с организациями как узлами.
3. Разделить people-only представление на полноэкранные редакционные главы.

## Решение

Presentation experiment использует `GraphAtlas`: одновременно показывается одна глава из конфигурации Tesla → SpaceX → OpenAI → PayPal → Zip2. Организация задаёт визуальную территорию и членство, но не отображается узлом. Членство строится только из опубликованных отношений с общим evidence source.

Для каждой главы `ChapterGraphLayout` один раз вычисляет нормализованные позиции из chapter ID, member IDs и layout version. Runtime-физика, pan и постоянный zoom отсутствуют. Переход между главами морфит общих людей между фиксированными позициями; остальные узлы появляются или уходят через scale/opacity. Pinch даёт временное увеличение `1...1.35×` и возвращается к auto-fit.

`Canvas` рисует только маршруты выбранного человека в активной главе. Прямое person-to-person отношение усиливает линию; shared context остаётся тонким; `disputed` использует пунктир и обязательный текстовый статус в панели. Узлы остаются SwiftUI `Button`, а связи — структурированным списком.

Collapsed-панель становится плавающей glass-карточкой. `medium` и `expanded` остаются edge-to-edge sheet с ранее зафиксированными detents.

## Последствия и риски

Положительные:

- первый кадр получает ясную тему и визуальную иерархию;
- число линий ограничено текущим выбором, а не всем кластером;
- evidence semantics и доступный список связей сохраняются;
- schema v1 и canonical seed не меняются.

Отрицательные:

- chapter order становится редакционным решением и требует конфигурации;
- пользователь не видит весь кластер одним взглядом;
- качество морфа, жестов и auto-fit нужно подтвердить на реальных устройствах;
- нормализованная композиция должна отдельно выдержать Dynamic Type и минимальный экран.

Renderer остаётся `proposed` до ручного accessibility audit и измерения повторного морфа на самом слабом доступном iOS 18-устройстве. Цель — отсутствие кадров длиннее 33 ms; локальная проверка типов и unit-контрактов не доказывает достижение этой цели.
